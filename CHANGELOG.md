# Changelog

Mudanças notáveis do dbForgeLinux. O projeto ainda está em desenvolvimento; esta lista registra o estado inicial documentado.

## 0.1.0 — Estado inicial

- Base desktop Electron, TypeScript, React, Monaco e driver MySQL/MariaDB.
- Editor SQL, conexão, grid com paginação em disco, histórico, designers, comparação e ferramentas por módulo.
- Cofre de senhas cifrado, opções Linux e associação de arquivos `.sql` no pacote Debian.
- Testes unitários, integrações opt-in, smoke de desktop e matriz honesta de cobertura em documentação.

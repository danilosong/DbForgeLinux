# AI Assistant

Configure um provedor e teste a conexão nas opções do assistente. No painel, faça uma pergunta ou peça ajuda com SQL; contexto de schema pode ser incluído conforme a configuração.

Use apenas provedores confiáveis. Não envie credenciais ou dados sensíveis no prompt. O assistente gera sugestões que devem ser revisadas antes de executar.

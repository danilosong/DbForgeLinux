# Source Control

Abra **Source Control**, selecione ou crie uma pasta de projeto e revise o status do Git. Use diff para inspecionar alterações, prepare os arquivos e informe uma mensagem para commit. Branches e operações remotas ficam disponíveis no painel quando o repositório permite.

As operações Git atuam na pasta selecionada. Confira o caminho e o diff antes de gravar ou enviar alterações.

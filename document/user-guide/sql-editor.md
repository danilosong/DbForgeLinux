# Editor SQL

1. Abra **New SQL** ou abra um arquivo `.sql` pelo menu de arquivo.
2. Escolha a conexão ativa e escreva a instrução no editor.
3. Use **Execute** para rodar a seleção ou o script; resultados aparecem abaixo do editor.
4. Salve o documento para manter o SQL em arquivo.

O histórico de execução e a formatação estão descritos em [Autocomplete, snippets e histórico](autocomplete-history.md). Revise comandos que alteram dados antes de executar.

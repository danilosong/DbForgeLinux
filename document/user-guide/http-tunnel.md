# HTTP Tunnel

Nas propriedades de uma conexão, habilite **HTTP Tunnel** e informe o endpoint do tunnel PHP, timeout e validação TLS. Preencha usuário e segredo apenas se o endpoint exigir autenticação; teste a conexão antes de salvar.

O túnel precisa estar publicado e configurado no servidor remoto. Use HTTPS fora de ambientes locais e proteja o endpoint como uma credencial de acesso ao banco.

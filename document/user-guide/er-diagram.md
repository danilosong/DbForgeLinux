# Diagrama ER

Selecione uma conexão e um database para carregar tabelas e foreign keys. Organize o diagrama, registre relações virtuais quando necessário e salve o arquivo do diagrama para continuar depois.

Relações virtuais são anotações locais do diagrama; elas não criam constraints no servidor.

# Guias rápidos

Os guias descrevem fluxos disponíveis na aplicação e usam capturas já existentes em `document/evidence/ui/`. A cobertura automatizada e as lacunas estão na [matriz de paridade](../03-matriz-paridade.md). Para começar, crie ou selecione uma conexão e confirme que o servidor está acessível.

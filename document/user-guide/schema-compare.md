# Schema Compare

Escolha as conexões e databases de origem e destino, compare os objetos e revise o script gerado. Antes de sincronizar, inspecione cada operação, especialmente drops e alterações que removem colunas.

A comparação de schema não substitui backup nem revisão do SQL. O suporte a recursos específicos depende do servidor.

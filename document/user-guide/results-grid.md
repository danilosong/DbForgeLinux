# Grid de resultados

Execute uma consulta no [Editor SQL](sql-editor.md) para abrir o grid. O grid mostra colunas e linhas do resultado; resultados grandes são armazenados e lidos em páginas para limitar o uso de memória.

Use a barra de resultados para navegar e exportar conforme as ações disponíveis. O scroll não carrega todo o resultado para a memória de uma vez.

# Matriz de risco por ferramenta/menu

Revisão da Sentinela (especialista de segurança), 2026-10-22, sobre HEAD `fd5fca4` + árvore em andamento. Cada linha foi conferida no código (arquivo:linha); nada aqui vem só da documentação. Severidade: **BLOCKER / HIGH / MEDIUM / LOW**. "Prod" = conexão com `environment: 'prod'`.

Legenda de proteções: **CD** confirmação digitada · **CS** confirmação simples (`window.confirm`) · **PV** preview do SQL · **TX** transação/rollback · **RO** perfil somente leitura · **PM** privilégio mínimo · **TO** timeout · **LL** limite de linhas · **PR** tratamento especial para Production.
